# Node.js Web Application Security Audit Framework

A comprehensive security testing framework for Node.js web applications, designed to detect, explain, and fix common security vulnerabilities following OWASP guidelines.

## 🎯 Overview

This project provides an automated security audit system that:
- **Detects** code-level vulnerabilities in Node.js applications
- **Explains** security issues with references to OWASP and CWE standards
- **Fixes** vulnerabilities with secure refactored code
- **Tests** both vulnerable and secure implementations
- **Reports** findings in structured JSON format

## 🔍 Vulnerability Coverage

The framework detects and mitigates:

1. **SQL Injection** (CWE-89, OWASP A03:2021)
   - String concatenation in queries
   - Unparameterized SQL statements
   
2. **Command Injection** (CWE-78, OWASP A03:2021)
   - Shell command execution with user input
   - Unsafe use of `exec()` and `spawn()`

3. **Hardcoded Credentials** (CWE-798, OWASP A07:2021)
   - Passwords, API keys, and secrets in source code
   
4. **Path Traversal** (CWE-22, OWASP A01:2021)
   - Directory traversal attacks
   - Insecure file access

5. **Insecure File Handling** (CWE-400, CWE-732, OWASP A04:2021)
   - Missing file size limits
   - Incorrect file permissions
   
6. **Insufficient Input Validation** (CWE-20, OWASP A03:2021)
   - Missing validation on user inputs
   
7. **Information Disclosure** (CWE-200, OWASP A01:2021)
   - Exposure of sensitive data in responses
   - Verbose error messages

## 🚀 Quick Start

### Prerequisites

- **Node.js** 14+ and npm 6+
- **MySQL** 5.7+ (or use Docker)
- **Docker** (optional, for containerized testing)

### Installation

#### Option 1: Local Setup

1. **Clone or extract the project**
   ```bash
   cd v-qinjie_25_11_03
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Configure environment**
   ```bash
   cp .env.example .env
   # Edit .env with your database credentials
   ```

4. **Set up database** (if not using Docker)
   ```bash
   node setup-database.js
   ```

#### Option 2: Docker Setup

```bash
# Start all services
docker-compose up -d

# Check status
docker-compose ps
```

## 🧪 Running Security Tests

### One-Click Testing

**Windows (PowerShell):**
```powershell
# Test vulnerable application
.\run_security_test.ps1 vulnerable

# Test secure application
.\run_security_test.ps1 secure

# Run complete comparison
.\run_security_test.ps1 all
```

**Linux/Mac (Bash):**
```bash
# Make script executable
chmod +x run_security_test.sh

# Test vulnerable application
./run_security_test.sh vulnerable

# Test secure application
./run_security_test.sh secure

# Run complete comparison
./run_security_test.sh all
```

### Manual Testing

**1. Static Security Audit**
```bash
node security-audit.js vulnerable-app.js vulnerability-report.json
```

**2. Start Applications**
```bash
# Terminal 1 - Vulnerable app
npm run start:vulnerable

# Terminal 2 - Secure app
npm run start:secure
```

**3. Run Dynamic Tests**
```bash
# Test vulnerable app
node security-tests.js http://localhost:3000 vulnerable-results.json

# Test secure app
node security-tests.js http://localhost:3001 secure-results.json
```

**4. Compare Results**
```bash
node compare-results.js vulnerable-results.json secure-results.json comparison.json
```

## 🔬 Test Categories

### SQL Injection Tests
- OR condition bypass (`' OR '1'='1`)
- UNION attacks
- Comment injection (`--`)
- Time-based blind injection

### Command Injection Tests
- Command chaining (`;`, `&&`, `|`)
- Command substitution (`` ` ``, `$()`)
- Multiple command execution

### Path Traversal Tests
- Directory traversal (`../../../etc/passwd`)
- Windows paths (`..\\..\\`)
- URL-encoded paths
- Absolute paths

### File Upload Tests
- Path traversal in filenames
- Executable uploads
- Large file DoS attacks

### Information Disclosure Tests
- Environment variable exposure
- Verbose error messages
- Debug endpoints

## 🛡️ Security Fixes Implemented

### Vulnerable Code Example:
```javascript
// SQL Injection vulnerability
const query = `SELECT * FROM users WHERE username = '${username}'`;
connection.query(query, callback);
```

### Secure Code Example:
```javascript
// Parameterized query prevents SQL injection
const query = 'SELECT * FROM users WHERE username = ?';
connection.query(query, [username], callback);
```

### Key Security Improvements:

1. **Parameterized Queries** - Prevents SQL injection
2. **Input Validation** - Regex patterns and whitelisting
3. **Environment Variables** - Removes hardcoded secrets
4. **Path Sanitization** - Prevents directory traversal
5. **execFile() Usage** - Prevents command injection
6. **Request Size Limits** - Prevents DoS attacks
7. **Proper Error Handling** - Prevents information leakage

## 📈 CI/CD Integration

### GitHub Actions Example

```yaml
name: Security Audit

on: [push, pull_request]

jobs:
  security-test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - uses: actions/setup-node@v2
        with:
          node-version: '18'
      - run: npm install
      - run: node security-audit.js vulnerable-app.js report.json
      - run: |
          if [ -s report.json ]; then
            echo "Security vulnerabilities detected!"
            exit 1
          fi
```

## 🔧 Customization

### Adding New Tests

Edit `test-data.json`:

```json
{
  "category": "Your Category",
  "tests": [
    {
      "name": "Test Name",
      "endpoint": "/endpoint",
      "method": "GET",
      "params": { "param": "malicious_value" },
      "expected_vulnerable": "What happens in vulnerable app",
      "expected_secure": "What happens in secure app"
    }
  ]
}
```

### Adding New Vulnerability Checks

Edit `security-audit.js`:

```javascript
checkYourVulnerability(content, fileName) {
  const pattern = /your-pattern/gi;
  const matches = content.match(pattern);
  if (matches) {
    this.addVulnerability({
      type: 'Your Vulnerability Type',
      severity: this.severityLevels.CRITICAL,
      description: 'Description',
      recommendation: 'How to fix'
    });
  }
}
```
