## 🔐 Explanation of Fixes (Secure App)

- Removed hardcoded credentials → uses environment variables (see .env.example).
- Replaced string interpolation with parameterized query:
  Insecure: SELECT * FROM users WHERE username = '${username}'
  Secure:   pool.execute('SELECT * FROM users WHERE username = ?', [q.username])
- Added Ajv schema validation to restrict allowed characters and length.
- Added Helmet to set common security headers.
- Isolated DB access via a pooled async connector instead of a single mutable connection.
